21.1 Access Groups: tab "Nhóm quyền"

This page (/settings/access-groups, card "Phân quyền truy cập" in 20.1) allows the Clinic Owner to define dynamic access groups: which screens and actions a group may use. A group is then assigned to staff members (21.2). The page needs the permission to view access groups; the buttons that change data need the permission to manage groups.

Header
← Quay lại / BreadcrumbButton and read-only path "Thiết lập / Bảo mật và lịch sử / Phân quyền truy cập". Returns to 20.1.
Segmented controlSwitches between "Phân quyền truy cập" and "Lịch sử thiết lập".

21.2 Access Groups: tab "Gán cho nhân viên"

This tab shows the staff members and the access group and business branches assigned to each. The base role of a staff member decides which groups can be assigned.

Field NameDescription
Nhân viênRead-only. Name, with the tag "Đã khóa" when the account is locked.
Vai tròRead-only. Roles of the staff member.
Nhóm quyềnRead-only. Name of the assigned group, or "Theo quyền vai trò hiện hành" when none is assigned.
Chi nhánh nghiệp vụRead-only. Branches in which the staff member works, or "Chưa có".
Gán nhóm quyềnButton. Opens the dialog 21.4. Shown only with the permission to assign access to staff. Disabled for the user's own row and for a Clinic Owner.

21.3 Access Group Dialog

This dialog opens from "Thêm nhóm quyền" (add) or "Thiết lập" (edit or view) in 21.1. Title: "Thiết lập phân quyền". When editing, the first save shows a preview of the effect and the user saves again to confirm.

Field NameDescription
Tên phân quyềnText, required, up to 160 characters.
Mã phân quyềnText, required, up to 40 characters.
Vai trò nềnSelect, required. Trợ lý phòng khám, Bác sĩ, Quản trị viên. Disabled when the group already has staff. Changing it removes the grants that do not belong to the new role.
Mô tảTextarea, up to 1000 characters.
Alert (chỉ xem)Read-only. "Bạn đang thuộc nhóm này. Thay đổi cần được thực hiện bởi người quản lý khác." or "Bạn có quyền xem nhóm phân quyền." The whole form is read-only.
Tìm quyềnText. Filters the grant list by name or key. Parents of a match stay visible.
Danh sách quyềnTree of checkboxes. Each screen is a parent and its actions are children. Checking a child also checks its parents; unchecking a parent unchecks its children. A grant outside the base role is disabled with "· Theo vai trò chuyên môn khác". A user who is not the Clinic Owner can only grant permissions that the user has.
Lý do thay đổi phân quyềnTextarea, up to 1000 characters. Required when editing an existing group.
Ảnh hưởngRead-only. Shown after the preview: the number of affected staff members, the grants added and the grants removed.
Alert (error)Read-only. Error message. When the group was changed by someone else (MSG111) the button "Đọc lại phiên bản nhóm, giữ bản nhập" loads the new version and keeps the input.
HủyButton. Closes the dialog. With unsaved changes it asks "Bỏ thay đổi phân quyền chưa lưu?" (Bỏ thay đổi / Tiếp tục sửa).
Xem trước thay đổi / Lưu phân quyền / ĐóngPrimary button. When editing: first "Xem trước thay đổi", then "Lưu phân quyền". When adding: "Lưu phân quyền". When the form is read-only: "Đóng". Name, code and the reason (when editing) must be filled; otherwise MSG02.

21.4 Assign Access Group Dialog

This dialog opens from "Gán nhóm quyền" in 21.2. Title: "Gán nhóm quyền · [tên nhân viên]".

Field NameDescription
Nhóm quyềnSelect, required. Only active groups whose base role matches the staff member's role, and (for a user who is not the Clinic Owner) whose grants the user also has.
Alert (thông tin)Read-only. "Chưa có nhóm đang dùng phù hợp với vai trò nhân viên. Tạo nhóm phù hợp trước khi gán." when the list is empty.
Chi nhánh nghiệp vụMulti-select, required. Only branches the staff member joined and the user may manage.
Lý do gán nhómTextarea, required, up to 1000 characters.
Alert (error)Read-only. Error message. For MSG111 the button "Đọc lại phiên bản nhân viên và nhóm" reloads both.
HủyButton. Closes the dialog.
Lưu nhóm cho nhân viênButton. Saves the assignment. Missing group, branch or reason gives MSG02. Disabled without the permission to assign.

21.5 Change Group State Dialog

This dialog opens from "Ngừng dùng" or "Khôi phục" in 21.1. Title: "Ngừng dùng nhóm quyền" or "Khôi phục nhóm quyền".

Field NameDescription
Group nameRead-only. Name of the group with the reminder that a group with staff must have its staff moved first.
Lý do đổi trạng tháiTextarea, required, up to 1000 characters.
Alert (error)Read-only. Error message. For MSG111 the button "Đọc lại trạng thái nhóm" reloads the group.
HủyButton. Closes the dialog.
Xác nhận trạng tháiButton. Switches the group between active and inactive. Disabled without the permission to manage.

21.6 Access Change History Drawer

This drawer opens from "Lịch sử phân quyền" in 21.1. It shows the latest 100 changes of access groups in the user's permitted scope.

Field NameDescription
Alert (error)Read-only. Error message with the button "Tải lại lịch sử".
Thời gianRead-only. Date and time of the change.
Người thực hiệnRead-only. Name of the staff member, or "#id" when not found.
Thao tácRead-only. "Thiết lập nhóm", "Gán nhóm" or "Đổi trạng thái".
Lý doRead-only. The reason entered.
Empty"Chưa có thay đổi phân quyền."
