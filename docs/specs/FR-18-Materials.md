# III. Functional Requirements

## 18. Instruments and Materials ("Dụng cụ - vật liệu")

Wireframes: https://www.figma.com/design/pqJcfUUOdMXZvXmx0gnxHi (frames "18.1" to "18.6").

### 18.1 Purchase Log (tab "Nhập hàng")

This screen (/materials, menu "Dụng cụ - vật liệu", group "Chuyên môn") allows a user to see and manage the purchases of instruments and materials: filter them, add, edit and delete a purchase. The tabs shown depend on the permissions to view purchases, stock and usage history.

| Field Name | Description |
|---|---|
| **Header** | |
| Title | Read-only. "Dụng cụ - vật liệu". |
| Tabs | "Nhập hàng", "Tồn kho", "Lịch sử xuất dùng". A tab is shown only to users who can view it. |
| **Filters** | |
| Từ / Đến | Date. The purchase date range. "Từ" cannot be after "Đến". Changing a date returns to page 1. |
| Tất cả các loại dụng cụ/vật liệu | Text, up to 160 characters, clearable. Searches by name. The search runs when the user presses Enter or clicks the search button; clearing the text shows all rows. |
| Mọi trạng thái thanh toán | Select. "Chưa thanh toán", "Còn nợ", "Đã thanh toán đủ". Clearable. |
| Làm mới | Button. Reloads the list. |
| Tổng cộng / Đã trả / Còn lại | Read-only. Totals in ₫ of all purchases that match the filters, not only the current page. |
| **Alerts** | |
| Alert (error) | Read-only. The error message with the button "Thử lại" when the list cannot be loaded; "Thử lại danh mục" when the materials cannot be loaded. |
| Alert (info) | Read-only. "Chưa có dụng cụ/vật liệu trong danh mục. Hãy thêm danh mục trước khi ghi nhập hàng." |
| **Purchase table** | |
| Ngày nhập | Read-only. Date the purchase was entered. |
| Ngày nhận | Read-only. Date received, or "Chưa nhận". |
| Hạn dùng | Read-only. Expiry date with the tag "Sắp hết hạn" (within 90 days) or "Hết hạn" (past), or "—". |
| Số lô | Read-only. Lot number or "—". |
| Tên dụng cụ/vật liệu | Read-only. Name and category, and "NCC: [company]" when a supplier is set. |
| SL | Read-only. Quantity with the purchase unit. When the usage unit differs, "= n [usage unit]" is shown below. |
| Đơn giá / Tổng cộng | Read-only. Unit price and total in ₫. |
| Đã thanh toán | Read-only. Amount paid in ₫ with the tag "Chưa thanh toán", "Còn nợ" or "Đã thanh toán đủ". |
| Nút "+" (header of last column) | Button. Opens the dialog 18.2 in add mode. Disabled without the permission to create or when the catalog has no material. |
| Sửa | Icon button. Opens the dialog 18.2 in edit mode. Disabled without the permission to update. |
| Xóa | Icon button. Opens the dialog 18.4. Disabled without the permission to delete. |
| Empty | "Chưa có lần nhập hàng nào." |
| Paging | 20, 50 or 100 rows per page (default 20) and "Có n kết quả." |

### 18.2 Add / Edit Purchase Dialog

This dialog opens from "+" or "Sửa" in 18.1. Title: "Thêm lần nhập hàng" or "Sửa lần nhập hàng".

| Field Name | Description |
|---|---|
| Alert (error) | Read-only. The error message. When editing and the purchase was changed by someone else, the button "Đọc lại phiên bản, giữ nội dung" loads the new version and keeps the user's input. |
| Ngày nhập | Date, required. Cannot be after today. Default is today. |
| Ngày nhận | Date. Cannot be after today. |
| Hạn dùng | Date. |
| Số lô | Text, up to 60 characters. |
| Dụng cụ/Vật liệu | Select, required, searchable. Options are grouped by category. |
| Số lượng | Number, required, greater than 0. Default 1. |
| Đơn vị | Text with suggestions (cái, lọ, miếng, hộp, tuýp, chai, ống, bộ, gói, túi, g, mL), required, up to 40 characters. |
| Quy đổi sang đơn vị dùng | Shown only when the material has a usage unit. "1 [purchase unit] = [factor] [usage unit]". The factor is required and greater than 0 (default 1). Below it the form shows the converted quantity and the price per usage unit. |
| Công ty cung cấp | Select, searchable, clearable ("Không chọn"). The button "+" opens the dialog 18.3; it is disabled without the permission to create providers. |
| Đơn giá (₫) | Integer, required, 0 or more. |
| Đã thanh toán (₫) | Integer, required, 0 or more. Cannot be greater than the total. |
| Tổng / Còn nợ | Read-only. Total = quantity × unit price; "Còn nợ" = total − paid. A warning is shown when the paid amount is greater than the total. |
| Hủy | Button. Closes the dialog. Disabled while saving. |
| Lưu | Button. Saves the purchase. Errors of a field are shown under that field. A retry of the same content uses the same request key, so no duplicate is created. The whole form is disabled without the permission. |

### 18.3 Add Supplier Dialog

This dialog opens from the button "+" next to "Công ty cung cấp" in 18.2.

| Field Name | Description |
|---|---|
| Alert (error) | Read-only. The error message. |
| Tên công ty | Text, required, up to 160 characters. The code of the company is generated by the system. |
| Hủy | Button. Closes the dialog. Disabled while saving. |
| Lưu | Button. Creates the company and selects it in 18.2. |

### 18.4 Delete Purchase Dialog

This dialog opens from "Xóa" in 18.1. Title: "Bạn có muốn xóa lần nhập hàng này không?".

| Field Name | Description |
|---|---|
| Summary | Read-only. "[material] · [entered date] · [total] ₫". |
| Alert (error) | Read-only. The error message, with the button "Đọc lại phiên bản" when the purchase was changed by someone else. |
| Không đồng ý | Button. Closes the dialog. |
| Đồng ý | Button. Deletes the purchase and reloads 18.1. Disabled without the permission to delete. |

### 18.5 Stock (tab "Tồn kho")

This tab shows the stock of instruments and materials. Every row is one purchase (one lot). It is read-only.

| Field Name | Description |
|---|---|
| Tìm tên dụng cụ/vật liệu | Text, clearable. The search runs 300 ms after the user stops typing. |
| Alert (error) | Read-only. The error message. |
| Dụng cụ/vật liệu | Read-only. Name and category. |
| Số lô | Read-only. Lot number or "—". |
| Ngày nhận | Read-only. |
| Hạn dùng | Read-only. Expiry date with the tag "Sắp hết hạn" (within 90 days) or "Hết hạn", or "—". |
| Công ty | Read-only. Supplier or "—". |
| Đã nhập / Đã dùng | Read-only. Quantity received and used, in the usage unit. |
| Còn lại | Read-only, bold. Received − used. |
| Empty | "Chưa có dụng cụ/vật liệu." |
| Paging | 20, 50 or 100 rows per page. |

### 18.6 Usage History (tab "Lịch sử xuất dùng")

This tab lists the quantities of materials used in treatment. Rows are created when a dentist records the materials used in a treatment sheet (see 9.12). It is read-only.

| Field Name | Description |
|---|---|
| Tìm tên dụng cụ/vật liệu | Text, clearable. The search runs 300 ms after the user stops typing. |
| Alert (error) | Read-only. The error message. |
| Thời gian | Read-only. Date of use. |
| Dụng cụ/vật liệu | Read-only. |
| Số lượng | Read-only. Quantity with the usage unit. |
| Bệnh nhân | Read-only. |
| Chi nhánh | Read-only. |
| Hồ sơ | Read-only. Code of the treatment sheet or "—". |
| Người ghi nhận | Read-only. Who recorded the use, or "—". |
| Empty | "Chưa có lần xuất dùng nào." |
| Paging | 20, 50 or 100 rows per page. |
