17.1 Reference Price of Treatment

This screen (/commercial/treatment, menu "Giá và duyệt điều trị", group "Chuyên môn", title "Giá tham chiếu điều trị") allows a user to see the reference price of every treatment service in the branch scope and to change the reference price and the unit of a service. The permission "Xem bảng giá điều trị" or "Xem duyệt thương mại điều trị" is needed to see the screen and "Thiết lập giá điều trị" to change a price. A change of the reference price does not change the agreed price of an existing treatment plan: old plans keep their snapshot.

ConcurrencyThe save sends the version of the price that was read. If someone else changed the price first, the save is rejected and the user must reload. Each opening of the dialog uses a new request key, so a retry of the same save does not create a duplicate.
