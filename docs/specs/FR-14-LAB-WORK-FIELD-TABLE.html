14.1 Lab Work Management

This screen (/lab-orders, menu "Quản lý công việc labo", group "Chuyên môn") allows a dentist to see all the lab orders (prosthetic work sent to a dental laboratory) and how many are in each status, to filter and search them, to open one to see its detail, to move it to the next status and to open the full lab order to edit it. The permission "Xem màn Quản lý công việc labo" is needed. The lab order itself is created from a treatment sheet.
