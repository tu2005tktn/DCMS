# Dental model attribution

Original models: **University of Dundee, School of Dentistry** (https://sketchfab.com/DundeeDental).
License for every model listed below: **Creative Commons Attribution 4.0 International**, https://creativecommons.org/licenses/by/4.0/.
The license and author were verified against each original model metadata and the Sketchfab public model API on 2026-10-27. No CC BY-NC jaw models are included.

Original files were retrieved from this pinned mirror revision:
https://github.com/sameralseedbth-Dental/dental-3d-models/tree/b8f428bd81a19b7041e3aad149e7dac7f38fd269

DCMS adaptations: world transforms baked; cervical origin, orientation and illustrative uniform scale normalized per template; root geometry cropped for the arch LOD; mesh simplification; original textures removed and illustrative enamel/root colors added; right-side teeth reflected from corresponding left-side templates. The per-tooth detail LOD retains full crown and roots. Source and derived SHA-256, file sizes and triangle counts are in manifest.json. The 26 source templates are reused for 52 FDI positions, not 52 separately scanned teeth.

These are educational reference shapes, not patient scans. No anatomical/clinical validation of this DCMS adaptation has been performed, and it is not intended for diagnosis, tooth/canal counting, length measurement or treatment planning from geometry.
