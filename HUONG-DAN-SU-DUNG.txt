========================================================================
  HUONG DAN CHAY VA DEMO DU AN DCMS (Dental Clinic Management System)
========================================================================

I. CHUAN BI (CHI CAN LAM 1 LAN)
------------------------------------------------------------------------
1. Docker Desktop
   May nay Docker Desktop nam o:
     %LOCALAPPDATA%\Programs\DockerDesktop\Docker Desktop.exe
   Mo no va doi ~1 phut cho engine san sang.

2. File .env da co san o thu muc goc DCMS (chua cau hinh DB, JWT va
   DEV_SEED_PASSWORD). KHONG commit file nay len Git.

3. Neu chua co web/.env:
     Copy-Item web\.env.example web\.env

4. Neu chua co thu muc web/node_modules:
     cd web
     npm.cmd install
     cd ..


II. CHAY TOAN BO PROJECT (MO 3 TERMINAL TAI THU MUC DCMS)
------------------------------------------------------------------------
Terminal 1 - Database (PostgreSQL):
     docker compose --env-file .env -f infrastructure/docker/compose.yaml up -d
     docker compose --env-file .env -f infrastructure/docker/compose.yaml ps
   (doi den khi cot Status la healthy)

Terminal 2 - API:
     # Lan dau hoac khi co migration moi (migrate + seed xong tu thoat):
     & .\infrastructure\scripts\start-api.ps1 -Migrate -SeedDemo

     # Chay API:
     & .\infrastructure\scripts\start-api.ps1

Terminal 3 - Web (Vite):
     cd web
     npm.cmd run dev


III. KIEM TRA DA CHAY CHUA
------------------------------------------------------------------------
     Invoke-RestMethod http://localhost:5080/health
   Ket qua mong doi: {"api":"healthy","database":"healthy"}

   Mo trinh duyet: http://localhost:5173/sign-in


IV. TAI KHOAN VA MAT KHAU DEMO
------------------------------------------------------------------------
Cac tai khoan demo (dung chung mot mat khau):
     admin.demo      - Quan tri vien (co menu Quan ly tai khoan)
     owner.demo      - Chu phong kham + Nha si
     dentist.demo    - Nha si
     assistant.demo  - Tro ly phong kham
     dual.demo       - Nha si + Tro ly
     guest.demo      - Public/Guest

Mat khau: mo file .env o thu muc goc DCMS, lay gia tri cua dong
     DEV_SEED_PASSWORD=...
(Dung PowerShell:  Get-Content .env | Select-String DEV_SEED_PASSWORD)

LUU Y: mat khau chi ton tai trong .env noi bo may ban. Khong paste mat
khau vao chat cong khai, anh chup man hinh hoac file commit len Git.


V. DEMO NHANH (10 PHUT)
------------------------------------------------------------------------
1. Dang nhap admin.demo -> xem trang "Tai khoan cua toi" (vai tro duoc
   cap / vai tro hieu luc).
2. Vao "Quan ly tai khoan": tim kiem, tao nhan vien, sua vai tro,
   khoa/mo khoa tai khoan, xem nhat ky audit.
3. Vao "Khoi phuc tai khoan" (http://localhost:5173/recover):
   - Buoc 1: nhap username -> thong bao trung lap (MSG12)
   - Buoc 2: nhap ma xac minh
     + Chua cau hinh kenh gui that, o Development doc ma qua API:
       (1) dang nhap admin.demo, lay accessToken
       (2) POST /api/auth/recovery/request  {"identifier":"dentist.demo"}
       (3) GET  /api/dev/recovery/proof/{accountId}  (kem Bearer token)
     - Buoc 3: dat mat khau moi (theo chinh sach hien thi tren man hinh)
   - Buoc 4: dang nhap lai bang mat khau moi; mat khau cu bi tu choi.
4. Dang xuat.


VI. CHAY KIEM THU TU DONG (TUY CHON)
------------------------------------------------------------------------
     # Backend: unit + integration
     & .\infrastructure\scripts\test-accounts.ps1

     # Browser (can API + Vite dang chay; cai Chromium 1 lan)
     cd web; npx.cmd playwright install chromium; cd ..
     & .\infrastructure\scripts\test-accounts.ps1 -Browser


VII. TAT VA DON
------------------------------------------------------------------------
- Tat API va Web: nhan Ctrl+C trong terminal tuong ung.
- Dung database:
     docker compose --env-file .env -f infrastructure/docker/compose.yaml down
   Them -v vao cuoi lenh neu muon xoa sach du lieu demo va seed lai tu dau.


VIII. LOI THUONG GAP
------------------------------------------------------------------------
- Docker bao loi ket noi: mo Docker Desktop truoc, doi engine san sang.
- Build bi bao "file is locked": terminal API dang chay va giu DLL,
  dong API (Ctrl+C) roi build/chay lai.
- /health tra ve 503 database unavailable: container Postgres chua
  healthy, doi them vai giay.
- Script PowerShell bi chan: chay
     Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
  trong chinh terminal do.
- Quen mat khau demo: xem DEV_SEED_PASSWORD trong .env.
- Build web bi bao chunk > 500 kB: chi la canh bao, khong anh huong.
